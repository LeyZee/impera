Fait : plugin `two-factor` de Better Auth (code TOTP, dix codes de secours chiffrés, appareil de confiance 30 jours, verrouillage après 10 échecs) ; migration 0061 (`two_factor`, `user.two_factor_enabled`, `session.reauthenticated_at`) ; 403 `second_factor_forbidden` pour un compte sans code actif ; confirmation mot de passe + code (`POST /v1/auth/reauthenticate`) lue par `requireRecentLogin` ; fermeture des sessions, lien de nouveau mot de passe, départ et `ops:reset-second-factor` suppriment les appareils de confiance ; mots de passe connus des fuites refusés (Pwned Passwords) ; écrans de connexion en deux étapes, d'activation et de codes de secours ; champ de code sur toutes les confirmations.
