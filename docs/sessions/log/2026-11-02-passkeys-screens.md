# 2026-11-02 — Face ID à l'écran : connexion, confirmation, clés d'accès (CR-01 lot c, 2e partie, fil espaces)
Fait : client des clés d'accès (`apps/web/src/auth/passkeys.ts`, `@simplewebauthn/browser` 13.3.0), bouton « Se connecter avec Face ID » (le nom du geste suit l'appareil : Face ID, Touch ID, ton empreinte, Windows Hello), proposition « Te connecter avec Face ID la prochaine fois ? » après une connexion par le code, une fois par appareil et seulement si l'appareil porte des clés, « Confirmer avec Face ID » dans la confirmation des actions sensibles (jamais pour ajouter une clé, jamais avec la clé qu'on retire), panneau « Clés d'accès » dans Réglages › Sécurité, Moi › Sécurité et `/compte/securite`, « N clés » et « Retirer ses clés » dans la vue du propriétaire ; la confirmation par mot de passe et code passe à la ligne sur un téléphone au lieu de déborder du panneau.
