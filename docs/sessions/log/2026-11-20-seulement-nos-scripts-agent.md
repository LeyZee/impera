# 2026-11-20 — ADR 0161 § 4 et § 5 : l'agent n'offre que nos scripts — in progress
Fait : `agentScriptViewOf` n'accepte plus qu'une copie reconnue d'un de nos scripts préparés (`ours`, lu par le module des scripts dans la même transaction). Elle n'est plus offerte si Reveal l'a changée depuis (nombre d'étapes, branches, prix ou devise différents des nôtres). Le cerveau lit la description et le moment de notre script ; l'identité d'un script natif n'est plus lue. Le Playground suit le même filtre. Tests : copie reconnue, natif non reconnu même avec une identité validée, copie changée chez Reveal, deux cents scripts natifs sans aucun des nôtres donnent un catalogue vide.
Pas fait : retrait des routes d'identité des scripts natifs (valider, corriger), prévu avec ce lot par l'ADR 0161 § 8 : il touche le module des scripts et ses droits, il part dans une PR à lui avec une relecture Sécurité.
Découvertes : aucune.
