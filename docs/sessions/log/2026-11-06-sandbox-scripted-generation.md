# 2026-11-06 · Bac à sable : la génération scriptée (ADR 0075 § 3, phase 2)

- Fiche : `docs/sessions/tasks/PROPOSED-recette-sandbox.md`, phase 2, confiée au fil Agent par le coordinateur après la relecture de #616.
- Fait : le faux monde répond à `POST /xai/v1/responses` comme xAI (`apps/api/src/__tests__/sandbox-world/ai-generation.ts`, branché par une ligne dans `world.ts`). La réponse est construite à partir du schéma JSON que la vraie passerelle envoie : un brief calme pour le cerveau, une réponse courte dans sa voix pour la voix, des notes moyennes pour le juge, une description neutre pour les sens. `/__/ai/next` choisit la prochaine réponse (`ai_disclosure`, `payment_link`, `meeting`, `off_schema`, `rate_limited`, `neutral`) ; chaque piège sert une fois. Aucun jeton : chaque appel est journalisé à 0 $. La clé passe par la même règle que son vérificateur (`refus`, `credit`, `limite`, `panne`, ou le mode forcé sur xAI).
- Tests : `ai-generation.test.ts`, par la vraie passerelle (`createAppLlm`) en HTTP local : brief et voix à 0 $, chaque piège une fois puis calme, hors schéma puis réparé, 429 puis réessai, clé refusée, script inconnu refusé ; et la réponse la plus simple de chaque schéma (cerveau, voix, sens, captures de tendance) passe le schéma.
- Découvertes : la génération par Google, Mistral et ElevenLabs n'est pas scriptée (503, le repli passe par xAI) ; la voix clonée et la transcription restent hors du bac à sable.
- Retour du lot Agent : l'ouverture de la voix tournait avec le compteur de tous les appels, donc la même revenait à chaque fan (cerveau puis voix) ; elle tourne maintenant sur les seules réponses de la voix. Ajout du script `risk` (`{"reply":"risk","risk":"…"}`, `minor_suspected` par défaut) : le prochain cerveau lit ce risque, pour jouer A7.
