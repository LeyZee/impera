# VEI-04 Profil de contenu : ce qui marche chez elle et ce qu'elle sait faire
Statut : blocked (clé de vision)
Phase : veille (ADR 0060)
Dépend de : VEI-01, CR-06
Branche : task/vei-04-content-profile
Propriétaire : Agent

## Objectif
Un profil de contenu par créatrice, rédigé par la vision à partir de ses propres médias, relu et validé par l'agence.

## Contexte à lire
ADR 0060 § 3, ADR 0030, ADR 0010.

## À faire
- [ ] Dépôt de l'export officiel des données Instagram de la créatrice (archive), lecture des médias seulement, archive effacée après.
- [ ] Description par la vision (images clés et transcription pour une vidéo), profil en brouillon, écran de relecture pour le propriétaire ou un manager ; seule la version validée est lue.
- [ ] Rafraîchissement mensuel, sans jamais écraser la version validée.

## Critères d'acceptation
- Tests avec une archive fabriquée ; la créatrice ne lit jamais son profil (RLS).

## Hors périmètre
Les statistiques de son compte (VEI-05).
